# Simple PDF Reader для Android

Простая и лёгкая читалка PDF-файлов для Android, написанная на **Kotlin** и **Jetpack Compose** с использованием встроенного системного движка `android.graphics.pdf.PdfRenderer` (без тяжёлых сторонних нативных библиотек).

## Возможности
- **История открытых документов (Недавние документы)**:
  - Сохраняет список ранее открытых PDF-файлов с датой открытия и общим числом страниц.
  - Сохраняет постоянный доступ к файлам (`takePersistableUriPermission`), чтобы они открывались в один тап даже после перезапуска телефона.
  - **Автоматически запоминает страницу**, на которой вы остановились, и продолжает чтение с того же места.
  - Возможность удалить отдельный файл из истории или очистить всю историю.
- Открытие любого PDF-файла через системный файловый пикер (не требует разрешений на доступ ко всем файлам устройства).
- Открытие PDF-файлов напрямую из других приложений / проводника («Открыть с помощью...»).
- Вертикальная постраничная прокрутка с ленивой подгрузкой страниц.
- Масштабирование щипком (Pinch-to-Zoom) и двойным тапом, а также кнопка быстрого сброса масштаба.
- Индикатор текущей страницы и общего количества страниц в верхней панели.

## Автоматическая сборка через GitHub Actions (без Android Studio)

В проект добавлен workflow [`.github/workflows/android-build.yml`](.github/workflows/android-build.yml), который автоматически собирает готовый к установке `app-debug.apk` на серверах GitHub при каждом `git push`.
